# 外链助手 v0.11.3

更新时把新包的 `extension` 文件覆盖到原目录，在 Edge 扩展管理页点「重新加载」。保留原扩展 ID、历史和本机资源。关闭旧桥接终端，在新包根目录用 `python .\codex_bridge.py --extension-id 你的扩展ID` 启动新版桥接；用新配对码启用 Codex CLI，并测试连接。

## 收集

- Ahrefs：在原网页完成验证并打开明细，点击「获取 Ahrefs 外链」。
- Semrush：在装有扩展的 Edge 中登录 sem.3ue.co。输入域名或镜像报告链接后点「获取 Semrush 外链」，首次允许读取镜像。扩展自动打开报告、切换明细并保存当前已加载的来源页。若需采集手动翻页后的数据，清空输入框，在明细页点击扩展图标后再采集。无需 CDP 或本机桥接。
- 博客：在文章标签页点击扩展图标。「判断是否可免登录留言」调用 Codex CLI 分析表单及登录提示，不提交试探评论。「收集评论和站长网址」读取已加载的公开评论和作者网址，跳过同站作者资料链接。评论分页、折叠或懒加载需要先展开或翻页，再补采。

## 资源库与发布

来源网址按查询目标或来源文章分组保存。同一个目标下相同网址不重复入库。评论正文按文章在本机保存，作者网址列为待验证候选。博客判断只代表页面证据，不证明该网站接受评论、已发布链接或链接是 dofollow。

在资源库可点击网址仅打开，或使用「打开填写并提交」走原有发布流程。需要先人工检查时，在设置里关闭自动提交。JSON 导出包含分组和供旧版本导入的扁平链接；公开评论正文留在本机资源库。

## SPAM 筛选

资源库的已收集外链支持全部、仅非 SPAM、排除 SPAM、SPAM / 高风险、待复核、未知。筛选记忆在本机，并用于 JSON 导出，不删除原始记录。Semrush 采集仅在表格存在明确 SPAM 状态列或 Toxicity Score 列时记录风险证据及时间；没有风险数据的旧记录、Ahrefs 和评论来源显示未知。Page AS 不用于风险判断。Toxicity Score 的本地规则：0–44 低风险，45–59 待复核，60–100 高风险。明确 SPAM 标记优先。此分类不保证安全或可发布。重新采集相同网址会更新可用风险证据；未提供新证据时保留已有证据及其时间。


## 自动分析与递归

默认开启“收集后自动调用 Codex 分析并收集评论站长网址”。首次需要允许读取来源网站；先启用 Codex CLI 桥接。Ahrefs / Semrush 收集结果保存后，逐页读取评论表单证据、调用模型判断，再保存已加载公开评论及站长网址。不会试投验证。已有资源点“分析已有资源”。失败、未处理任务可点“继续分析 / 重试失败”。保持侧边栏打开；关闭后队列保留，但未完成的任务需要点继续。

递归轮数由用户填写 0–5。0 只分析本次来源页；1 再查询一轮评论站长域名的 Semrush 反链并分析；2 再扩展一次，以此类推。查询按域名去重，文章按 URL 去重；已查询域名复用保存的当前加载结果。用户后续提高轮数可继续扩展，已有任务不会因下调输入值被删除。自动递归使用 Semrush 镜像登录会话；Ahrefs 仍从手动验证后的结果采集。报告未加载、登录失效或桥接错误会暂停；可停止。只包含当前已加载的评论与报告行，不代表全量数据。

## 胶囊筛选与发布

资源库有全部、博客评论、个人主页、可发布、已发布、失败、有验证码胶囊筛选；个人主页指评论作者公开网址，未经验证不保证是个人主页。卡片按 URL 去重，悬停显示来源目标；目标分组保留在 JSON。SPAM 筛选可叠加，CSV / JSON 导出跟随筛选。删除卡片只移除资源，保留提交账本。

发布页输入要推广的域名。首次使用该域名还需填写真实昵称和邮箱，或预先导入同域名产品资料。使用 Codex CLI 从文章正文生成相关评论，推广网址填入网站字段。默认每批最多 5 篇，可设置 1–50；仅处理疑似免登录且未处理的博客，排除已知 SPAM。提交防重沿用本机账本，等待审核不算已发布；结果未知、验证码、登录、多表单或失败时批次停止，人工处理后再开始。发布状态按当前产品区分。停止无法撤回已发出的提交。

此版本通过隔离浏览器中的模拟页面、模拟模型及模拟提交回归；未向真实博客发布测试评论，也未验证真实 Semrush 当前登录会话的递归流程。

## 当前网页自动识别

打开插件或切换当前标签页时，自动将网页域名填入 Ahrefs、Semrush 和发布域名输入框；报告页面提取查询目标，不使用服务站点本身的域名。手动修改过的字段不被覆盖，点“使用当前网页”恢复自动识别。任务运行期间不切换目标。此功能使用 tabs 权限读取标签页网址，升级时浏览器可能要求确认新增权限。普通网站点击 Ahrefs 会打开对应查询页，完成验证后再点获取；Semrush 可直接打开并采集当前网站的报告。

- 博客评论可点击明确的展开/加载更多按钮，或同文章的标准评论分页链接。每篇默认最多 3 页/批，可设 1–20；每批保存并去重。只处理可见公开评论，不点击登录、提交或跨站按钮。不支持的动态组件/iframe 标记人工检查。手动“收集评论和站长网址”也使用此流程。
- 资源卡的“留言方式与链接证据”记录网站字段、已有正文链接、嵌入式评论和已有链接 rel。已有正文链接只代表历史证据，不代表该站现在一定允许发布。勾选“重新检查已分析资源的页面证据”后点“分析已有资源”，可更新旧资源。
- 发布方式可选自动提交或半自动；半自动填写一篇即暂停，交由用户检查提交。提交后仅在匹配新评论中核对目标链接，记录实际 rel；评论显示但没发现链接不等于外链成功；当前浏览器可见不等于已独立核验匿名公开。
- 不包含利用换行或特殊字符绕过站点 nofollow/ugc 的功能；不调用表单原型 submit 绕过页面验证，不规避验证码或反垃圾规则。没有 nofollow/ugc/sponsored 也不等于搜索引擎保证传递权重。
- 本次不新增 Google Sheets 云端同步、跨域 iframe 编辑器或正文 HTML/Markdown 自动留链。帖子中的模型费用和成功率不作为本插件承诺。

验证：并发、代理、分页状态机、隔离浏览器的展开评论/rel 提取/提交链接核验/半自动选项兼容回归；未向第三方站点发布测试评论。真实站点分页结构各异，遇到未识别控件会停止，需要按实际页面补适配。

## 自动流程简化（v0.11.1）
移除“判断是否可免登录留言”“收集评论和站长网址”手动按钮及自动分析开关。获取外链并保存后固定自动执行这两步；仍可停止、继续或在资源库重新分析。无需重启桥接。

## 重复桥接修复（v0.11.2）
Windows 下桥接使用独占端口，拒绝第二个进程占用 8795，避免不同配对码的服务同时监听。端口已占用会明确退出而不是生成第二个可用服务。插件保存配对码前先调用 health 验证，失败不覆盖已存配对码。

## 搜索结果页排除（v0.11.3）
明确的 Yahoo/Google/Bing/百度/DuckDuckGo/Yandex 搜索结果页在分析前排除，不打开、不调用模型；跳转后再检测一次。原始采集记录保留，资源库可筛选“已排除”。新闻等正常内容页不按整个搜索服务品牌屏蔽。此类地址不作为新递归种子。无需重启桥接，停止分析并重新加载插件后继续。
