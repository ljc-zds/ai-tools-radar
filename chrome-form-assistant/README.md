# 外链助手 v0.6.0

**外链由你选择的本地文件提供，不打包在插件里。** 插件在浏览器中解析、搜索、打开目标并自动填写；模型由扩展直接调用，填写后默认自动提交一次，并检查网站回执。无需网关或配对令牌。

## 现在怎么用

1. 在 `chrome://extensions` 刷新插件（首次加载选择 `chrome-form-assistant/extension` 子目录），关闭旧侧边栏再打开。顶部版本 **v0.6.0**；已有产品、密钥、文件关联与记录保留。
2. 点击右上角 **设置**，填写 API Key 和模型并保存。服务地址、接口与推理强度在「高级模型参数」，已有私有配置或产品资料在「导入产品资料与模型配置」导入。设置不会自动展开，密钥不会回显。
3. 选择产品和场景，在目标网页点击插件图标，再点 **填写并提交当前页**。或者点击「本地外链」旁的 **选择文件**，导入 `local-resources/backlinks.json.gz` 或自己的文件，搜索并点某条 **打开填写并提交**。
4. 插件自动识别、生成、校验并填入空白字段，填写后重新校验并自动提交；验证码、登录、必填缺失、按钮歧义或内容变化会暂停。取消只在运行时显示；多个表单才要求选择。填写后显示撤销及可选提交记录。

参考 [autoComment](https://github.com/cloud-hu2000/autoComment) 将配置收进独立设置，日常操作收敛成填写当前页或打开外链填写。外链仍来自本地文件；主界面不再展示分步分析、生成和填入按钮。网址链接本身仍可仅打开查看。未设置模型时只提示右上角设置，不抢占界面。

## 本地文件配置

两种方式都只在本机解析和保存，**不上传服务器，也不把整个外链文件发给模型**：

- **导入文件副本**：选择一次，保存到当前 Chrome 扩展 IndexedDB，重启后仍可搜索；原文件改动时重新导入。
- **关联本地原文件**：通过浏览器文件选择器授予单个文件的读取权限，保存文件句柄；原文件改动后在设置的「文件与填写选项」中点击「刷新关联文件」。只显式刷新，不轮询。权限拒绝、文件移动/删除、解析失败时保留旧列表。浏览器不支持关联时用导入副本。

只能读取你在浏览器中选择的文件，不能输入任意系统路径让插件读取。当前只保留一个活动资源文件；切换文件后列表只显示新文件的 URL，原有每产品工作记录仍保留，用于重复提交提示。

支持以下格式（文件和解压后内容均最多 128 MiB）：

- JSON 数组：既有 `library.json` 的 `url`、`verified_blog_comments.json` 的 `post_url`、`data/links/*.json` 的 `u`；也支持 `[{"url":"https://example.com/post","title":"..."}]`、`items`/`links` 数组与构建器的紧凑聚合格式。
- CSV：BOM、逗号、换行、引号及双引号转义；URL 列名支持 url / post_url / u / Source URL / Referring page URL / 链接 / 网址 / 来源URL。
- TXT：每行一个 HTTP/HTTPS URL。
- 上述内容可 gzip 压缩为 `.json.gz` / `.csv.gz` / `.txt.gz`。

错误文件不会替换当前列表。危险 URL 会剔除并显示拒绝数量；敏感查询参数、凭据 URL 和 `#/...` / `#!...` 路由不进入列表。所有解析、解压和搜索在 Worker 中进行，每页只渲染 10 条，避免大文件阻塞界面。

## 已准备的完整本地快照

`local-resources/backlinks.json.gz` **在插件目录外**，汇总现有代码中安全的反链来源：

| 来源 | 原始行数 |
|---|---:|
| 历史博客评论记录 | 377 |
| library 候选 | 12,000 |
| 2,257 个 links 详情文件中的来源 `u` | 223,633 |

去重后 **181,878 个 URL**；详情行中 201 条不安全 URL 已拒绝。保留来源快照文件名、标题、平台、历史状态及观察/首次发现时间。不把 `data.json` 的目标域名当成反链来源，也不声称覆盖全网；原详情快照每域名最多约 100 条。

历史 live 只代表旧文件当时的记录，同日冲突标记 unknown。其他条目均是未验证候选，不代表有效外链、目录或可填写表单。列表不会后台访问这些 URL；只有你点击的目标会打开。

重新生成此本地文件（不是运行插件的前提）：

```sh
python3 chrome-form-assistant/build_browser_assets.py
```

读取既有公开快照和产品资料，默认输出 `local-resources/backlinks.json.gz` 与白名单 `extension/products.json`；不会读取模型密钥。`--data-dir`、重复 `--kit`、`--output-dir` 可指定来源与外部输出；禁止把反链目录输出到 extension。

## 自动填写的停止边界

- 只在你明确授权的具体网站读取和填入。跨域或路径跳转会暂停，显示原地址和新地址；点击继续才请求新域名权限。不会在新域名静默填写。
- 两个以上明确匹配表单时暂停，须选择表单后继续。验证码、登录、联系/注册/订阅表单或无法确认的表单会停止。动态表单最多等待 6 秒，页面加载最多 20 秒。
- 任务固定到原标签页、产品、场景、页面 URL 和文档快照；等待或模型返回后重新检查。点击取消后不再进入后续填写，可重新开始另一目标。
- 不覆盖已有值。只支持普通 form 中可见启用的 text/email/url/tel、textarea、select；iframe、富文本和非标准自定义控件暂不支持。
- 默认不派发 input/change 事件。兼容 React 的事件开关需主动选择，任务进行中会锁定；网站自己的事件可能自动保存或提交。默认自动提交通过明确且唯一的同源提交按钮完成；不处理验证码。开启输入事件兼容后自动提交会暂停，以免网站已自行提交。
- 已完成填写和失败的记录分开提示。页面已填而记录失败时不要重复填写。撤销保留你的后续修改；刷新/导航会清除页面内撤销记录。

## 自动提交与本机记录

本次目标显示产品与原始资源 URL；跳转后明确继续的任务仍关联原资源。网页提交后勾选「我已在原网页手动提交」再记录。此证据仅是人工确认与时间，不推断公开、收录或链接有效。

自动提交默认开启；可在设置 → 文件与填写选项关闭。提交前使用 IndexedDB 原子事务锁定产品与 URL，然后只点击一次。关闭侧栏、重启、断网、回执丢失或超时均保留防重锁，不会自动重试；重复导入与撤销也无法解除锁。

结果区分对应评论已出现（当前浏览器可见，不代表搜索收录）、等待审核、明确失败、暂停与结果未知。仅清空表单、跳转或泛化 Thanks 不算成功。目录站只有明确收到目录提交的回执才标记等待审核。无法识别的站点保守标记结果未知，需要人工检查。

验证码、登录、非唯一按钮、跨站提交、表单修改、已有同内容或同产品网站评论均暂停。提交后最多观察约 9 秒；关闭侧栏后不继续核验，保留结果未知。

每产品、每 URL 单独记录。产品身份是规范化产品 URL 的 SHA-256，与导入顺序无关。精确 URL 已确认提交后禁止重复填写；同域其他已提交 URL 会提示。撤销、跳过、重复导入都不降级已提交状态。

## 模型与密钥

默认 HTTPS 服务 `https://cubapi.codemao.cn/v1`、`gpt-5.6-sol`、Responses、推理 low。模型请求强制 `store:false`、`stream:false`、JSON 输出，无 temperature；最多 90 秒，禁止重定向/cookies。自定义模型 HTTPS 域名需单独授权，换域必须提供新 Key。HTTP 仅用于用户授权的目标网站，模型服务仍要求 HTTPS。

Key 只保存在扩展 IndexedDB，不发给内容脚本、目标网页、历史或资源文件。内容脚本没有读取配置接口，chrome.storage.local 限制为 TRUSTED_CONTEXTS。资料库只向模型提供当前目标的提取正文/字段说明与产品事实，不发送已填值、联系人字段或整份外链列表。错误不回显供应商原文。

浏览器本机数据库并非加密保险箱；卸载/清除数据会删除产品、配置、当前资源与工作记录。旧 SQLite 和原项目文件不修改。一次性私有迁移文件生成仍可用 `prepare_browser_profile.py`，输出 `.data/browser-profile.json` 权限 0600，切勿分享或放进扩展目录。

## 验证

```sh
python3 -m unittest discover -s chrome-form-assistant/tests -v
node chrome-form-assistant/tests/test_dom.cjs
node chrome-form-assistant/tests/test_sidepanel.cjs
node chrome-form-assistant/tests/test_loaded_extension.cjs
```

实际加载测试使用干净 Chrome for Testing、真实 tabs/scripting/permissions API 和本机合成表单；仅在临时测试 manifest 预授权 fixture 域名，未自动操作原生权限弹窗。OPFS 文件句柄存储/刷新是真实操作，原生文件选择器用测试替身。模型为模拟响应，不使用登录态/真实密钥，不对外提交。截图 `/tmp/form-assistant-v04.png`。

自动提交回归测试：`node tests/test_submission.cjs`。使用隔离 Chrome 和本地合成网站，覆盖真实 POST/跳转、审核、未知结果、持久化防重、并发锁、验证码、登录、编辑变化与一次性提交票据。

## 仓库版说明

此目录从独立插件仓库提交 `7c6f9bf` 集成。仓库版仅附带 Example Product 示例，请导入自己的产品资料；已有浏览器配置不受影响。外链数据默认读取本仓库 `data/`，产品资料默认读取 `outreach/kit.json`。密钥、私人产品配置、本地外链快照不随代码发布。
