# 外链助手 v0.7.0：用 Codex CLI 填写博客评论

1. 在 Edge 打开 `edge://extensions`，加载解压后的 `extension` 文件夹。更新旧安装时，把新扩展文件覆盖到原目录再点「重新加载」，以保留现有设置和记录。
2. 复制扩展管理页显示的 32 位扩展 ID。在压缩包解压目录打开 PowerShell，先运行 `codex login status` 确认已登录，再运行：

   ```powershell
   python .\codex_bridge.py --extension-id 你的扩展ID
   ```

3. 保持终端开启。把终端显示的 `Pairing token` 填入外链助手「设置 → Codex CLI → 本机配对码」，点击「启用 Codex CLI」，允许本机访问后点击「测试连接」。重启桥接会生成新配对码，需重新保存。
4. 导入真实产品资料，选择「博客评论」，打开一篇与产品相关、允许评论的文章，再点「填写并提交当前页」。模型根据文章生成评论，网址填入页面提供的网站字段。若想先检查草稿，先在「文件与填写选项」关闭自动提交。

桥接只监听本机，不读取或导出 Codex 登录令牌。模型生成走已登录的 Codex CLI，会使用其额度。浏览器仍使用现有表单校验、验证码暂停和防重复提交逻辑。没有网站字段、网站不允许链接、等待审核或提交后未公开时，不保证获得外链。请勿分享本机配对码。
