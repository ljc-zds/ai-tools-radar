# 本地收集的外链资源快照

条目数、分组数和导出时间见 `collected-backlinks.json` 的 `metadata`。

- `groups` 按查询目标或发现来源文章分组，`items` 是同一份数据的扁平视图，不应重复计数。
- 资源保留网址、标题、来源类别、留言判断、主题和页面质量。旧记录可能尚未分类，标签不影响发布资格。
- 快照生成时仍有分析任务运行；未完成和失败状态保持原样，不代表所有资源已验证，也不保证可发布或安全。
- 排除配对码、API Key、浏览器会话、邮箱配置、评论全文、表单数据及发布账本；移除常见认证查询参数。质量信号只保留类型，不含评论原文引用。
- 可在插件“本地外链 → 选择文件”读取 JSON 清单。导入清单不等于恢复浏览器中的分组、队列、分析状态或发布记录。

本次上传由资源拥有者明确授权。浏览器本地数据库未修改。
